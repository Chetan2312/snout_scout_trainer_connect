# Snout Scout Trainer Connect

Premium Android marketplace prototype for dog-trainer consultations in India.

## Tech stack
- Kotlin
- Jetpack Compose
- Material 3
- Navigation Compose
- MVVM
- Room
- Fake repositories and offline-first local state

## Build APK from GitHub Actions
1. Push code to `main`
2. Open the **Actions** tab
3. Open the latest **Build Android APK** run
4. Download the `snout-scout-debug-apk` artifact
5. Install the APK on your Android phone
